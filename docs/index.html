zenTTS

Un panel pequeño que lee en voz alta la página que tienes abierta, oración por oración, marcando por dónde va. Hecho para leer fanfics en Zen Browser.

Código en GitHub Cómo instalarlo

Qué hace

Lee solo la historia
Wattpad, AO3, FanFiction y Webnovel tienen extractores propios que saltan menús, comentarios y barras laterales. En cualquier otro sitio usa Readability.
Marca por dónde va
El párrafo actual se resalta y se desplaza a la vista, como Read Aloud de Edge.
Vista de lectura
Abre el texto extraído en una página limpia con la oración actual marcada. Serif, sans o mono; tamaño e interlineado ajustables.
Traducción
Opcionalmente traduce antes de leer, para escuchar una historia escrita en otro idioma.
Interruptor por sitio
Activa o desactiva el panel en cada dominio. Recuerda tu elección.
No estorba
Vive en un Shadow DOM: los estilos del sitio no lo tocan y él no toca los del sitio.

Sitios con extractor propio

  • Wattpad
  • Archive of Our Own
  • FanFiction.net
  • Webnovel

Dos motores de voz

Nativo Las voces que ya tiene el navegador (SpeechSynthesis). Nada que instalar; funciona en cuanto cargas la extensión.
Neural 45 voces neurales de Microsoft a través de edge-tts, servidas por un pequeño servidor Ruby en localhost:8765. Suena mucho más natural.

Instalación

  1. Linux, con Flatpak (recomendado)

    Ruby, edge-tts y trafilatura vienen incluidos.

    git clone https://github.com/JoVi-Yashi/zenTTs.git
cd zenTTs
make flatpak

    Luego busca zenTTS en el menú de aplicaciones.

  2. Instalación manual — Linux o Windows

    Necesitas Ruby 3.2+, y edge-tts y trafilatura en el PATH. En Windows, RubyInstaller con MSYS2.

    git clone https://github.com/JoVi-Yashi/zenTTs.git
cd zenTTs
make install
cd extension && npm install && cd ..
make build-extension
  3. Cargarla en Zen

    Ve a about:debugging, elige “Cargar complemento temporal” y selecciona extension/manifest.json.

    Si Zen está instalado como Flatpak, primero dale acceso a la carpeta:

    flatpak override --user \
  --filesystem=$HOME/Proyectos/zenTTs \
  app.zen_browser.zen
  4. App de escritorio (opcional)

    Una ventana GTK pequeña para arrancar y detener el servidor de voces neurales sin terminal.

    make gui
