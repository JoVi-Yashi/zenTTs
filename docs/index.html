Características

🎯

Shadow DOM nativo

El panel flotante usa Shadow DOM. El CSS del sitio nunca interfiere con la herramienta.

🔊

SpeechSynthesis

TTS nativo del navegador. Cero dependencias, cero servidores. Funciona apenas cargás la extensión.

📍

Highlighting en página

Resalta el párrafo actual en la página mientras se reproduce. Como Edge, pero en Zen.

📖

Extractores por sitio

Wattpad, AO3, FanFiction, Webnovel — cada uno con su propio extractor optimizado.

🌐

Site Manager

Activá o desactivá la herramienta por dominio. Con favicons reales y toggles.

🎨

Preview sincronizado

Pop-up con el texto extraído, subrayado en tiempo real al ritmo del audio.

Instalación

  1. Clonar el repo 
    git clone git@github.com:JoVi-Yashi/zenTTs.git
cd zenTTs
  2. Buildear la extensión 
    cd extension && npm install && cd ..
make build-extension
  3. Cargar en Zen

    Andá a about:debugging → Cargar complemento temporal → seleccioná extension/manifest.json

  4. Flatpak (opcional)

    Si Zen está en Flatpak, necesita acceso al filesystem:

    flatpak override --user --filesystem=$HOME/Proyectos/zenTTs app.zen_browser.zen
