zenTTS

Un panel pequeño que lee en voz alta la página que tienes abierta, oración por oración, marcando por dónde va. Hecho para leer fanfics en Zen Browser.

Así lee

De lo que hace

Extrae de la página solo la historia, sin menús, resúmenes ni comentarios, y la lee con la voz que elijas: la del propio navegador, las voces neurales de Microsoft o una voz que vive en tu equipo y no necesita conexión. Al terminar un capítulo trae el siguiente y sigue; cuando vuelves, recuerda dónde te quedaste.

El capítulo siguiente, sin pedirlo
En AO3, FanFiction.net y Wattpad el capítulo siguiente se carga en la misma página y la lectura continúa.
Donde lo dejaste
Cada capítulo guarda su punto; el botón ofrece «Continuar · 34 / 120».
Una voz que no te deja a medias
Si la voz neural deja de responder, la lectura sigue desde la misma oración con la voz local o la del navegador.
Vestido con los colores de tu navegador
Sigue el modo claro u oscuro y el tema de Firefox instalado; pega el valor de zen.theme.accent-color para igualar tu acento de Zen.
La vista de lectura
El texto extraído en una página limpia, con la oración actual marcada, en serif, sans o mono.
Traducción
Opcionalmente traducida párrafo a párrafo, para escuchar una historia escrita en otra lengua.

Las casas que conoce

  • Wattpad
  • Archive of Our Own
  • FanFiction.net
  • Webnovel

De las tres voces

Nativa Las voces que ya tiene tu navegador. Nada que instalar.
Neural Voces neurales de Microsoft mediante edge-tts, servidas por un pequeño servidor Ruby en localhost:8765. Las más naturales.
Local Piper dentro del navegador. Descargas una voz una vez (~60 MB) y funciona sin servidor ni conexión.

De cómo instalarlo

  1. Linux, con Flatpak

    Ruby, edge-tts y trafilatura vienen incluidos.

    git clone https://github.com/JoVi-Yashi/zenTTs.git
cd zenTTs
make flatpak
  2. A mano — Linux o Windows

    Necesitas Ruby 3.2+, y edge-tts y trafilatura en el PATH. El build prepara también el motor de voz local.

    git clone https://github.com/JoVi-Yashi/zenTTs.git
cd zenTTs
make install
cd extension && npm install && cd ..
make build-extension
  3. Cargarla en Zen

    Ve a about:debugging, elige «Cargar complemento temporal» y selecciona extension/manifest.json.

    Si Zen está instalado como Flatpak, primero dale acceso a la carpeta:

    flatpak override --user \
  --filesystem=$HOME/Proyectos/zenTTs \
  app.zen_browser.zen
  4. La app de escritorio, si quieres

    Una ventana pequeña para arrancar y detener el servidor de voces neurales sin terminal.

    make gui
