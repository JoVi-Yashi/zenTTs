◈ Características

◈

Shadow DOM nativo

El panel flotante usa Shadow DOM encapsulado. El CSS del sitio jamás interfiere con la herramienta — aislamiento total.

≋

Dos motores TTS

Elige entre SpeechSynthesis nativo (sin dependencias) o edge-tts con 45 voces neurales de Microsoft. Cambias desde el panel de ajustes con un click.

◎

Highlighting en la página

Resalta el párrafo actual directamente en el DOM del sitio mientras se reproduce. Como Edge Read Aloud, en Zen.

▣

Extractores por sitio

Wattpad, AO3, FanFiction, Webnovel — cada plataforma tiene su extractor optimizado con selectores específicos.

◉

Site Manager

Activa o desactiva la herramienta por dominio con toggle switches. Favicons reales. Persiste entre sesiones.

⬡

Flatpak · cualquier distro

Instala TTS-zen con un solo comando en Ubuntu, Fedora, Arch y cualquier Linux. Ruby, edge-tts, trafilatura — todo incluido en el sandbox.

◎

Preview sincronizado

Pop-up con el texto extraído y subrayado en tiempo real al ritmo del audio. Tipografía y espaciado ajustables.

▸ Instalación

1
Flatpak — Linux (recomendado)

Ruby, edge-tts, trafilatura, y launcher incluidos. Cero dependencias manuales.

git clone https://github.com/JoVi-Yashi/zenTTs.git
cd zenTTs
make flatpak

Después busca TTS-zen en el menú de aplicaciones.

2
Instalación manual — Linux / Windows

Linux: Ruby ≥ 3.2, edge-tts CLI, trafilatura CLI. Windows: RubyInstaller + MSYS2.

git clone https://github.com/JoVi-Yashi/zenTTs.git
cd zenTTs
make install          # gem install sinatra puma rackup gtk3
cd extension && npm install && cd ..
make build-extension
3
Cargar en Zen Browser

Abre about:debugging → Cargar complemento temporal → selecciona extension/manifest.json

Si Zen está en Flatpak:

flatpak override --user \
  --filesystem=$HOME/Proyectos/zenTTs \
  app.zen_browser.zen
4
App de escritorio

Abre la GUI para gestionar el servidor sin terminal:

make gui          # Linux
ruby gui.rb       # Linux / Windows

Modos de funcionamiento

Nativo

SpeechSynthesis del navegador. Cero dependencias. Funciona apenas cargas la extensión — sin servidor, sin setup.

Siempre disponible

Neural

45 voces neurales de Microsoft vía edge-tts. Server Ruby/Sinatra en localhost:8765. Cambias desde el panel ⚙ → Motor.
