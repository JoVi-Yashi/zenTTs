◈ Características

◈

Shadow DOM nativo

El panel flotante usa Shadow DOM encapsulado. El CSS del sitio jamás interfiere con la herramienta — aislamiento total.

≋

SpeechSynthesis del navegador

TTS nativo. Cero dependencias externas, cero servidores. Funciona inmediatamente después de cargar la extensión.

◎

Highlighting en la página

Resalta el párrafo actual directamente en el DOM del sitio mientras se reproduce. Como Edge Read Aloud, en Zen.

▣

Extractores por sitio

Wattpad, AO3, FanFiction, Webnovel — cada plataforma tiene su extractor optimizado con selectores específicos.

◉

Site Manager

Activá o desactivá la herramienta por dominio con toggle switches. Favicons reales. Persiste entre sesiones.

◎

Preview sincronizado

Pop-up con el texto extraído y subrayado en tiempo real al ritmo del audio. Tipografía y espaciado ajustables.

▸ Instalación

1
Clonar el repositorio 
git clone git@github.com:JoVi-Yashi/zenTTs.git
cd zenTTs
2
Buildear la extensión 
cd extension && npm install && cd ..
make build-extension
3
Cargar en Zen Browser

Abrí about:debugging → Cargar complemento temporal → seleccioná extension/manifest.json

4
Flatpak? Concedé acceso al filesystem

Si Zen está instalado vía Flatpak, necesita leer los archivos de la extensión:

flatpak override --user \
  --filesystem=$HOME/Proyectos/zenTTs \
  app.zen_browser.zen
